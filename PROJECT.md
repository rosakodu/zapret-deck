# zapret-deck: План интеграции новых возможностей

## Цель
Интеграция передовых решений из `zapret-discord-youtube-rust`:
1. Парсер Windows `.bat` стратегий в Linux аргументы `nfqws` с автоопределением портов.
2. Поддержка и обновление бинарных фейков Discord UDP и GameFilter.
3. Прямой модуль сокетного тестирования TLS 1.3 и автоподбора TTL (1–20) на Steam Deck.
4. Защита игрового трафика (GameFilter UDP).
5. Сетевая диагностика и детектор DNS-спуфинга.
6. Проверка занятости очереди NFQUEUE.
7. Автозагрузчик стратегий из GitHub (Remote Fetcher).

---

## Майлстоуны

- [x] **M1: Парсер стратегий и обновление фейков**
  - Модуль `bat_parser.py`: парсинг `.bat`/`.cmd` файлов, выделение портов `--wf-tcp`/`--wf-udp`, трансляция путей для Linux.
  - Поддержка актуальных бинарных фейков Discord UDP (`.bin`) в `bin/` и каталоге плагина.
- [x] **M2: Сокетный автоподбор TLS 1.3 и подбор TTL**
  - Модуль `autotune.py`: сокетные проверки TLS 1.3 ClientHello (без зависимости от сторонних curl-процессов), измерение задержек/успеха.
  - Алгоритм подбора TTL от 1 до 20 с модификацией аргументов стратегии (`--dpi-desync-ttl`).
- [x] **M3: Интеграция с бэкендом плагина и проверка**
  - Подключение парсера и нового автотюнера к `py_modules/zapret_deck/zapret_manager.py` и `main.py`.
  - Тестирование локально и валидация готовности к деплою на Steam Deck (`deploy.sh`).
- [x] **M4: Сетевая защита и диагностика (GameFilter, DNS, Queue Check)**
  - `gamefilter.py`: конфигурация портов онлайн-игр и предотвращение десинхронизации игрового UDP.
  - `diagnostics.py`: детектор DNS-спуфинга (сравнение с DoH 1.1.1.1/8.8.8.8) и проверка модулей ядра (`nfnetlink_queue`, `nft_queue`).
  - Проверка занятости `NFQUEUE 220` и автоосвобождение очереди в `zapret_manager.py`.
- [x] **M5: Автозагрузчик стратегий (Remote Fetcher) и RPC интеграция**
  - `remote_fetcher.py`: скачивание и парсинг свежих `.bat` стратегий из GitHub upstream.
  - Регистрация RPC методов в `main.py`.
  - Тестирование и проверка фронтенда.
